# ClassroomRWX

Web presentation do **Boteco RWX** para a live sobre **Classroom of the Elite**, cobrindo as temporadas 1 e 2 pela evolução das relações, regras da escola, alianças, máscaras e jogos de poder.

## Objetivo

Não é um resumo episódio a episódio. A apresentação foi estruturada como uma sequência de **cenas curtas + pergunta para a bancada + contexto**, para que Felipe conduza Will e KV pela história sem transformar a live em palestra.

## Estrutura narrativa

1. A escola parece um paraíso.
2. O sistema de pontos mostra os dentes.
3. Ayanokoji e Horikita começam a operar juntos.
4. Kushida revela a máscara.
5. A Classe D aprende a usar o sistema.
6. O teste da ilha mostra que existe alguém jogando por baixo.
7. Ayanokoji revela como enxerga as pessoas.
8. A temporada 2 transforma relações em armas.
9. Kushida tenta jogar e encontra contramedidas.
10. Ryuen caça o mastermind.
11. Ayanokoji sai das sombras.

## Como usar

Abra `index.html` em um navegador, ou publique o repositório via GitHub Pages.

Controles:

- `← / →`: slide anterior / próximo
- `Space`: próximo slide
- `N`: mostra/esconde as notas da bancada
- `F`: tenta entrar/sair de tela cheia
- `Esc`: fecha player/modal
- clique em **Tocar trecho** para abrir o player quando houver YouTube
- clique em **Abrir fonte** quando o trecho depender de episódio oficial ou fonte externa

## Regras operacionais para a live

- Usar somente o trecho necessário para sustentar a conversa.
- Preferir diálogo, sem opening/ending ou música isolada.
- Após o trecho, voltar imediatamente para a bancada.
- As faixas de tempo marcadas como **sugeridas** precisam ser conferidas antes da live.
- O botão de notas guarda as perguntas para Will/KV, ganchos e saída editorial do bloco.

## Arquivos

- `index.html`: shell da apresentação
- `styles.css`: identidade visual e layout 16:9
- `clips.js`: sequência editorial completa e fontes
- `app.js`: navegação, player, notas e atalhos
